# HCM // TRACE

An interactive web experience that begins with questions from 2026, traces the
historical formation of Ho Chi Minh Thought, and returns to the present.

The current implementation covers Phase 0 (Foundation) and Phase 1 (Homepage).
Trace content has not been implemented yet.

## Commands

```bash
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
```

Open [http://localhost:3000](http://localhost:3000) after starting the development
server.

Development and production builds use Next.js with Webpack because Turbopack
was unstable in the current Windows environment.
